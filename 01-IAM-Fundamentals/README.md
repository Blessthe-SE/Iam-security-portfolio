# Project 01 — IAM Fundamentals

## Overview

This project provides a practical foundation in Identity and Access Management (IAM), covering the core concepts, principles, identity lifecycle, access control, and risks associated with managing digital identities.

The project combines IAM theory with practical security and governance perspectives and serves as the foundation for subsequent hands-on IAM projects involving Microsoft Entra ID, AWS IAM, access governance, privileged access management, and IAM risk assessment.

## Objectives

- Understand the fundamentals of Identity and Access Management.
- Distinguish between identity, authentication, authorization, and access.
- Understand the identity lifecycle.
- Apply the principles of least privilege and need-to-know.
- Understand Role-Based Access Control (RBAC).
- Understand Privileged Access Management (PAM).
- Understand Segregation of Duties (SoD).
- Identify common IAM risks and control measures.
- Establish a foundation for practical IAM implementations.

## Identity Lifecycle

The IAM lifecycle generally involves:

1. Joiner — creation and provisioning of a new user's identity and access.
2. Mover — modification of access when a user's role or responsibilities change.
3. Leaver — removal or disabling of access when a user leaves the organization.

## IAM Risks

Common IAM risks include:

- Excessive user privileges
- Orphaned accounts
- Dormant accounts
- Delayed access revocation
- Privilege creep
- Unauthorized access
- Shared accounts
- Weak authentication
- Segregation of Duties conflicts
- Inadequate access reviews
